# mvc-high-street-gym-app

A full-stack gym management system developed using modern web technologies, following the MVC architecture and RESTful API principles.

## Technologies

### Backend

- [Node.js](https://nodejs.org/): Node.js is a JavaScript runtime environment that allows JavaScript to run on the server side. It is used in this project to build and run the backend application.
- [Express](https://www.npmjs.com/package/express): Express is a fast, minimalist web framework for Node.js. It is used to handle routing, middleware, and HTTP request/response management.
- [EJS](https://www.npmjs.com/package/ejs): EJS (Embedded JavaScript) is a templating engine that enables dynamic HTML generation. It is used for server-side rendering and generating dynamic XML export files.
- [MySQL2](https://www.npmjs.com/package/mysql2): MySQL2 is a Node.js MySQL client library that allows the application to communicate with the MySQL database. It is used for database queries and data management.
- [Bcryptjs](https://www.npmjs.com/package/bcryptjs): Bcryptjs is a library for securely hashing passwords. It is used to hash user passwords before storing them in the database.
- [Swagger JSDoc](https://www.npmjs.com/package/swagger-jsdoc): Swagger JSDoc generates OpenAPI documentation from JSDoc comments. It is used to document the RESTful API endpoints.
- [Express OpenAPI Validator](https://www.npmjs.com/package/express-openapi-validator): Express OpenAPI Validator validates API requests and responses against the OpenAPI specification to help ensure API consistency.
- [CORS](https://www.npmjs.com/package/cors): CORS is Express middleware that enables controlled cross-origin requests between the React frontend and backend API.

### Frontend

- [React](https://www.npmjs.com/package/react): React is a JavaScript library for building user interfaces. It is used to develop the interactive client-side application.
- [React Router](https://www.npmjs.com/package/react-router): React Router is a routing library for React applications. It is used to navigate between pages without reloading the entire application.
- [Tailwind CSS](https://www.npmjs.com/package/tailwindcss): Tailwind CSS is a utility-first CSS framework. It is used to style the application and create responsive layouts.
- [DaisyUI](https://daisyui.com/): DaisyUI is a component library built on top of Tailwind CSS. It is used to create reusable interface components and improve the application's design.
- [React Icons](https://www.npmjs.com/package/react-icons): React Icons provides a collection of popular icon libraries. It is used to add icons to the application's user interface.
- [Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API): Fetch API is a built-in JavaScript feature for making HTTP requests. It is used to communicate with the backend RESTful API and retrieve or submit data.
